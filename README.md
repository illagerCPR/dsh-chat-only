# dsh-chat-only

DeepSeek Harness 的 **Chat Only（仅对话）** 模式：一个只能联网、不能动本机的会话。

模型在这个模式里能看到的工具**只有两个**：

| 工具 | 作用 |
|---|---|
| `web_search` | 联网搜索，返回摘要与来源链接 |
| `web_fetch` | 抓取指定网址的正文 |

除此之外什么都没有——没有 Shell、没有文件读写、没有代码执行、没有子智能体、没有任务板、没有记忆工具、没有画布。模型无法在这台机器上创建、修改或删除任何东西。

## 为什么需要它

DSH 的 Web 版把大部分工具挪进了 preset 层，但**仍有一批工具注册在宿主层**，任何 preset 都会继承：`working_directory`、MCP 资源工具，以及第三方插件注册的工具。所以"少挂几个插件行"并不能得到一个干净的工具集。

这个包用一个**白名单**解决：在每个 Agent 的 scope 上施加 `tools.restrict({ allow: ['web_search', 'web_fetch'] })`，宿主层继承来的工具全部被隐藏。白名单是失败即关闭的——将来新增的工具默认不可见，不需要有人记得去拉黑。

## 安装

```sh
dsh plugin --profile web add @illager_aris/dsh-chat-only
```

安装后，新建会话时在模式选择器里选 **Chat Only**。

## 配置

本包没有配置项。它声明一个 preset（`chat-only`）和一个 guard 插件，两者都随包安装。

## 说明

- 长对话压缩与时间上下文保留：它们不是工具，不进入模型的工具列表。
- 不加载 `AGENTS.md`：项目指令面向编码任务，对纯对话是噪音。
- 模型仍会收到运行上下文（当前时间、工作目录等），但没有任何工具能利用它们。
